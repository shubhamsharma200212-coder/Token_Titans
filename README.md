# CareerMatch AI — HTML/CSS Frontend

A responsive hackathon frontend prototype built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and sections
- `style.css` — responsive dark SaaS styling
- `script.js` — navigation, resume file validation, demo report, roadmap progress, print/save

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Click **Analyze my resume** and try selecting a role.
4. The report uses clearly labeled illustrative demo data; it does not parse or upload the selected resume yet.

## Next step
Connect a backend (for example, Python FastAPI) to extract resume text, identify skills, compare against job requirements, and generate a real report. Never put an AI API key in frontend JavaScript.
